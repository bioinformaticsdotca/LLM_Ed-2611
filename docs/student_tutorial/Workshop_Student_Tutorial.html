Before you begin: the minimum vocabulary

In the biological examples, DNA (deoxyribonucleic acid) and RNA (ribonucleic acid) are sequences of units called nucleotides. A protein is a chain of amino acids; an amino acid in the chain is a residue. The sequence letters specify these units, not their three-dimensional positions.

A model is a mathematical rule that turns an input into an output. Its adjustable numbers are parameters. Machine learning (ML) means using examples to determine some of those parameters. Training, also called fitting, is that adjustment process. Prediction, also called inference, applies an already fitted model. Downloading data or loading a model is not itself training.

A dataset is a collection of observations. An observation, or sample, is one item being analyzed. A feature is an input measurement describing it. A target is the answer a model is meant to predict; a categorical target is often called a label. For example, one RNA is a sample, its length is a feature, and its existing coding/noncoding annotation is a label. The annotation is not automatically an independently verified experimental fact.

In supervised learning, training examples include targets. Classification predicts categories; regression predicts numerical values. Unsupervised learning fits patterns without those targets. Clustering is an unsupervised task that groups similar inputs. These ideas are worked through in Chapter 2; no model knowledge is assumed beforehand.

1. Retrieve biological data

Understand the request before running it

A database stores records: individual entries with identifiers, often called accessions. A sequence is an ordered nucleotide or amino-acid string. An annotation describes a record, such as its organism. A gene summary and a fetched sequence are different objects.

An application programming interface (API) lets programs communicate. An endpoint is the address for an operation. Your code sends a request with parameters describing the desired records and receives a response. These are request settings, not learned model parameters. HTTP is the communication protocol: status 200 usually indicates success, 429 a request-rate limit, and 5xx a server error. None establishes biological correctness.

GET requests information; POST supplies a request body for processing. Either can support a search. JSON, JavaScript Object Notation, is structured text with named values and lists. response.json() converts it to Python objects; this is inappropriate for non-JSON responses.

The recurring pattern is request → inspect → parse → validate → save. To parse is to separate structured text into usable components. Provenance is the record of where the data came from and what was done to them.

Understand the model’s inputs and answers

Here a row represents one RNA sequence, and the intended label is coding or noncoding. Coding RNA carries instructions used to make a protein; a long noncoding RNA (lncRNA) is an RNA annotated as noncoding and longer than short noncoding-RNA classes. The word “lncRNA” in a query does not prove every returned record belongs to that class.

Feature engineering means choosing and calculating numerical descriptions of the inputs. This notebook uses nucleotide length, GC percentage, and a simple open-reading-frame length. GC percentage is 100 times the fraction of G or C letters. An open reading frame (ORF) is a candidate run of codons read without an intervening in-frame stop. A reading frame specifies where those three-letter codons begin. The supplied helper looks for AUG-started runs in three frames and reports a length in nucleotides.

Illustrative input only: a row [600, 48.0, 300] means length 600 nucleotides, GC 48%, and the helper’s ORF-length value 300. Those are not three observations; they describe one observation. The label is stored separately and must not be included as an input feature. [N2, Part 2; B1]

Step 2.5 — Fit three kinds of classifier

A classifier predicts a category. A decision tree learns a sequence of questions about features, such as whether an ORF-length feature exceeds a threshold. A random forest combines many trees trained with random variation in examples and candidate features. The combined prediction can be more stable than that of a single tree, but this must be checked.

Logistic regression is also a classifier here, despite its name. It learns a weighted score from the features and converts it into estimated class probabilities: numbers between 0 and 1 assigned to the possible categories. With three features, the score has the form w1 × feature1 + w2 × feature2 + w3 × feature3 + b. The fitted weights w1, w2, w3 and offset b are parameters. You need not derive the probability formula to use it.

Step 2.7 — Read the errors, not only one score

Before running evaluation, define positive as the class coded 1: noncoding in this notebook. A true positive is a noncoding RNA predicted noncoding. Precision asks: among positive predictions, how many are correct? Recall asks: among truly positive examples, how many were found? F1 combines precision and recall as 2 × precision × recall / (precision + recall) when that denominator is nonzero.

3. Transformers, representations, and Hugging Face

Notebook: 04_Transformers.ipynb · Parts 0–4; Part 5 is optional. Companion: 04_slides.pdf. [N3; H1]

What happens between a sequence and a prediction?

A language model learns patterns in sequences of symbols. For this exercise the symbols describe amino acids, not prose. A pretrained model has already had its parameters learned from a training collection. You will use those parameters for inference, not retrain them.

A token is one unit processed by the model. A tokenizer splits an input into tokens and assigns integer token IDs from a vocabulary, the set of recognized tokens. An ID is a lookup index, not a meaningful numerical measurement: ID 20 is not “twice” ID 10 biologically.

An embedding is a numerical vector representing a token or input; recall that a vector is an ordered list of numbers. A learned lookup converts token IDs to initial embeddings. A contextual representation changes according to the surrounding input. A neural network is a model that processes inputs through layers of learned numerical transformations. A transformer is a neural-network architecture that builds contextual representations using a mechanism called attention.

Attention computes weighted combinations of representations; these input-dependent weights differ from the fixed model parameters learned in training. Its learned query, key, and value vectors are numerical projections: queries are compared with keys to calculate weights, which combine values. These are not database queries. One attention head performs one such calculation; several heads operate within a layer.

Tiny illustrative example: weights 0.2, 0.3, 0.5 on vectors [1,0], [0,1], [1,1] yield [0.7,0.8]. The weights determine the mixture. They do not, by themselves, establish which biological interaction caused a prediction.

A model head is the output component for a task. A masked-language-model head outputs a logit, an unnormalized numerical score, for each possible token at a hidden position. Softmax transforms those logits into nonnegative probabilities that sum to 1 over the vocabulary. The probability is conditional on the input and model; it is not a measurement of protein function.

Step 3.5 — Inspect attention without treating it as an explanation

Do — Part 3; cells 37–46. Inspect A.shape: after removing special-token rows and columns, the supplied model produces (6, 20, 76, 76). An axis is one dimension of an array. For average attention distance, dist[i,j] = |i-j| is the separation along the sequence. Multiplying by weights, summing over j, and averaging over i gives one number per layer/head, hence shape (6,20). Illustratively, weights 0.8 and 0.2 at distances 1 and 6 give weighted distance 2.

5. AlphaGenome: predict effects of genomic changes

Notebook: 06_AlphaGenome.ipynb · Parts 0–3; Part 4 contains optional extension and troubleshooting. [N5]

What is predicted, and from which input?

AlphaGenome predicts molecular signals from DNA. It is not a conversational assistant. Python runs in Colab; the model runs through a hosted API. You request inference, not training on these data.

A genome assembly, or genome build, is a particular reference sequence and coordinate system. This notebook uses human GRCh38, also called hg38. A locus is a genomic region. A variant describes a difference from a reference sequence; its reference allele is the reference sequence at the site and its alternate allele is the proposed replacement. An SNV is a single-nucleotide variant, one base replaced by another.

Genes have a strand, the direction in which their sequence is read. The supplied mutation table uses alleles on the forward genomic strand even when the gene lies on the reverse strand. Genomic positions and protein positions are different coordinate systems.

A transcript is an RNA copy from a gene. Exons are the portions retained in a spliced transcript; introns are removed. Splicing joins exons, using signals near donor and acceptor boundaries. The notebook groups variants as splice-related, nonsense (creating a premature stop), missense (changing an amino acid), synonymous (not changing the amino acid), or synonymous near a splice region. These annotations describe types of change, not guaranteed effects on RNA abundance.

6. ESMFold: from a protein sequence to predicted coordinates

Notebook: 07_Folding.ipynb · Parts 0–4; Part 5 is optional. [N6]

Structure is a different prediction target

Folding stability concerns a protein’s tendency to retain a folded state under specified conditions. Protein function concerns what it does, such as binding another molecule or catalyzing a reaction. Neither is measured merely by drawing predicted coordinates.

ESMFold combines a protein language model with a folding head, the component that predicts three-dimensional structure. It takes an amino-acid sequence and outputs coordinates and confidence estimates. It does not simulate a molecule physically folding over time. A wild-type sequence is the reference sequence for the comparison; a mutant differs from it.

A protein domain is a region with a structural or functional role. Selected fragments reduce computing cost. An isoform is an alternative protein form, potentially with different numbering. Check reference identity and coordinates before mutation.

The exercise compares structural summaries with cell-line measurements. A predicted structure is not an assay of activity, stability, or degradation.

Step 6.1 — Check the data and choose the execution route

Do — Part 0; cells 3–4. Load the approved ccle_multiomics_panel.csv. Verify that it has the RNA, protein, and mutation columns and that it is your validated handoff or an explicitly supplied reference copy.

FOLD_MODE="api" sends sequences to the hosted service; "local" runs inside Colab on a suitable GPU. Local here is still cloud computation, not your computer. Model downloads and memory demands can be substantial; timing estimates are not guarantees.

The helper may reuse a structure or fall back to GPU computation. A hash is a fingerprint of input bytes, used here to name saved structures by sequence. Record the route: a hash alone does not document the model version, settings, or a fresh run.

Step 6.2 — Parse substitutions and check reference residues

Do — Part 1; cells 6–9. p.R175H means reference residue R at protein position 175 is replaced by H. A missense substitution changes an amino acid. A stop change and a frameshift, which changes the translation frame, are different kinds of variation.

A regular expression is a pattern for recognizing text. The supplied parser recognizes p. followed by one letter, digits, and one letter. Its returned tuple contains reference residue, integer position, and new residue. Several changes separated by ; can be returned separately.

Check. Run the parser checks and verify the reported reference residues against UniProt. Matching position 175 requires sequence[174] because Python starts at 0. Unexpected isoforms or naming conventions need review, not forced substitutions.

A PDB file is a text structure format. In a predicted PDB, atom lines contain coordinates. An angstrom (Å) is a length unit equal to one tenth of a nanometre. A C-alpha atom, written CA, is a backbone atom used here as one representative coordinate per residue.

It is not the probability that the protein folds or is functional. A low score may reflect several causes, including flexibility, disorder (lack of one stable local conformation), missing context, or model uncertainty; it is not a definitive disorder experiment. 7. Make sense of confidence and disagreement

Notebook: 08_result_sense.ipynb · Parts 0–6; optional extensions follow. [N7]

Define the question before comparing the models

AlphaFold2 is a protein-structure predictor. ColabFold provides a practical workflow for running structure prediction, including AlphaFold2. A multiple sequence alignment (MSA) arranges related sequences into corresponding positions, providing evolutionary context. ESMFold instead uses a protein language model at inference without requiring that alignment search. Different inputs and architectures do not imply statistically independent evidence: training sources and biases can overlap.

You already met pLDDT, which concerns local structural accuracy. pTM, predicted template modelling score, estimates overall structural agreement on a 0–1 scale. It is not a measured folding probability. A local score and a global score can differ without logically contradicting one another. [B5]

This notebook studies GB1, the B1 domain of protein G, a small 56-residue domain. Its hydrophobic core contains residues that pack away from water. The experiment substitutes selected positions with aspartate, denoted D, and compares the confidence scores. This is a stress test, not a direct measurement of folding stability.

Evidence boundary. The supplied notebook calls a variant “impossible” and says it “cannot fold.” It does not include an experimental stability measurement for that exact variant. For your report, distinguish the notebook’s biological hypothesis from the observed model scores. Use “strongly perturbed core variant” rather than turning the premise into measured ground truth. Short self-check answers

1. Retrieval: A successful response establishes communication success, not that the requested organism, molecule, or annotation was returned. The supplied FASTA is local input; the API exercises are separate requests.

2. ML: Rows of X contain input features. Matching entries of y contain target labels. .fit() uses paired examples; .predict() applies the learned rule to inputs. Evaluation requires separate target information and a defensible data split.

3. Transformers: An ID names a token; an embedding is a numerical representation; attention weights mix representations; masked-token probabilities are task-specific outputs. None alone is a measured function.

4. Publications: Join on the full biological key. A source sentence must exist, concern the intended population and endpoint, and support the stated value. Exact substring matching checks only part of this.

5. AlphaGenome: Build, position convention, reference allele and strand must agree. Model outputs in reference contexts and observations across different cell lines are not paired experimental interventions.

6. Folding: A small difference between predicted backbones does not prove unchanged activity or stability. The protein-minus-RNA score is a difference of standardized measurements, not a fitted prediction residual.

7. Confidence: Confidence concerns a particular prediction task. Model agreement is not ground truth, and different architectures do not guarantee independent evidence. A claim about stability needs independent stability evidence.
